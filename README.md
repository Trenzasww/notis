# Notis

Tus notas, archivos y calendario en una web app privada y gratuita. Sin servidor propio, sin API de pago.

- Chats contigo mismo (notas, resúmenes, fotos, videos, PDF, Word, links de YouTube con vista previa)
- Archivos guardados byte por byte (calidad original, 4K); las ediciones no destructivas nunca tocan el original
- Editor de fotos (recorte, relación de aspecto, zoom, giro, filtros) y de videos (recorte de tramo, encuadre, mute)
- Calendario, buscador y 64 paletas (claro / oscuro / personalizada)
- Sincronización opcional con tu propio Google Drive (carpeta oculta de la app, usa tus 15 GB gratis)

## Instalar en iPhone
Safari → Compartir → "Añadir a pantalla de inicio".

## Sincronizar
Ajustes → "Sincronizar con tu Google Drive" explica cómo crear el Client ID (una vez, gratis).

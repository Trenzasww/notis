# Notis

Tus notas, archivos y calendario en una web app privada y gratuita. Sin servidor propio, sin cuentas, sin API de pago.

- Chats contigo mismo (notas, resúmenes, fotos, videos, PDF, Word, links de YouTube con vista previa)
- Archivos guardados byte por byte (calidad original, 4K); las ediciones no destructivas nunca tocan el original
- Editor de fotos (recorte, relación de aspecto, zoom, giro, filtros) y de videos (recorte de tramo, encuadre, mute)
- Calendario, buscador y 64 paletas (blanco y negro por defecto, modo claro/oscuro)
- Color por nota y por chat: contorno o vidrio de color

## Vincular tu PC y tu celu (directo, sin nube ni cuentas)
Ajustes → "Vincular tus dispositivos". En uno tocás "Vincular un dispositivo" y aparece un código; en el otro, "Tengo un código" y lo escribís.
Después, cuando los dos tienen Notis abierto al mismo tiempo, se sincronizan solos, en calidad original y sin límite de tamaño.
Los datos van cifrados de un dispositivo al otro (WebRTC). Un servicio público gratuito (PeerJS) solo ayuda a que se encuentren.

## Instalar en iPhone
Safari → Compartir → "Añadir a pantalla de inicio". Abrí el código de vinculación desde la app instalada, no desde Safari.

## Opcional: respaldo en Google Drive
Ajustes → "Avanzado". Requiere crear un Client ID de Google (gratis).
